# SettleIn 🏡

**Find your place. Discover opportunities. Settle in.**

SettleIn is a modern real estate and property marketplace mobile application built with React Native and Expo. It provides a platform for users to discover properties, explore available spaces, and connect with property buyers and sellers.

The application is designed to simplify property discovery through an intuitive interface, location-based exploration, and a seamless mobile experience.

## ✨ Features

- **Property Discovery** – Browse and explore available property listings.
- **Multiple Categories** – Discover houses, offices, halls, and properties for sale.
- **Property Details** – View property information, images, pricing, and location.
- **Location Exploration** – Explore property locations using interactive maps.
- **Buyer Experience** – Discover properties and explore available opportunities.
- **Seller Experience** – A platform for showcasing and managing property listings.
- **Modern UI** – Clean layouts, responsive components, smooth animations, and intuitive navigation.
- **Image Selection** – Support for selecting property images.
- **Cross-Platform** – Built to support Android, iOS, and web.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git
- Expo Go or an Android/iOS development environment

### 1. Clone the repository

```bash
git clone https://github.com/emmanjoseph/settle_in_app.git
```

### 2. Navigate into the project

```bash
cd settle_in_app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npx expo start
```

### 5. Run the application

After starting the development server, you can:

- Press `a` to open the Android emulator.
- Press `i` to open the iOS simulator.
- Scan the QR code using Expo Go where supported.
- Press `w` to run the web version.

## 📱 Application Categories

SettleIn focuses on the following property categories:

- **Houses** – Residential properties and homes.
- **Offices** – Commercial and professional spaces.
- **Halls** – Event and multipurpose spaces.
- **Selling** – Properties available for purchase.

## 👥 User Roles

The platform is designed around three user roles:

- **Buyers:** Discover properties and explore available listings.
- **Sellers:** Showcase properties and reach potential buyers.
- **General Users:** Browse the platform and explore available properties.

## 🎨 Development

The application uses Expo Router for file-based navigation and NativeWind for styling.

Reusable interface components are maintained in the `components` directory, while shared application utilities and logic are organized in `lib`.

To contribute or make changes:

1. Fork the repository.
2. Create a new feature branch.
3. Implement your changes.
4. Test the application.
5. Submit a pull request.

## 🔮 Project Vision

SettleIn aims to make property discovery and real estate opportunities more accessible through technology.

The long-term vision is to create a connected property marketplace where buyers, sellers, and property seekers can discover opportunities, explore locations, and interact through a unified platform.
